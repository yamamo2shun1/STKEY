# 新キーボード 回路設計スタートメモ

作成: 2026-11-25。現行C4NDY_STKの `C4NDY_STK.ioc` から実ピン割り当てを抽出し、新仕様（オーディオなし／HID+MIDI／エンコーダー×4／スティック別基板）と突き合わせた設計開始点。

## 現行STKのピン割り当て（STM32G491CE, LQFP48）
| ピン | 現行の役割 |
|---|---|
| PA0 / PA1 / PA4 / PA5 | アナログ入力（スティック×2のX/Y、SharedAnalog） |
| PB2 | アナログ入力（ミックス用ポット） |
| PA3, PA6, PA7, PB0, PB1, PB11 | QUADSPI（CLK / IO3 / IO2 / IO1 / IO0 / NCS）— 外付けFlash |
| PA8 / PA9 | I2C2（ADAU1761制御） |
| PB3 / PB4 / PB5 / PB6 | SAI1_B（SCK / MCLK / SD / FS）— コーデック |
| PA11 / PA12 | USB DM / DP |
| PA13 / PA14 | SWD |
| PA15 | TIM8_CH1（LED駆動、DMA） |
| PB7 / PB9 / PC15 | 74HC165系（SL / QH / CLK）キースキャン読み取り |
| PC13 / PC14 | 74HC164系（CLK / A）キースキャン駆動 |
| PB10 | USER_SW |
| PB12 / PB13 | USER_LED / LP_LED |
| PF0 | HSE入力 |

LQFP48はほぼ全ピン使用済み。未使用は PA2 / PA10 / PB8 / PF1 の4ピンのみ。

## 新仕様でのピンの出入り
- **空くピン（オーディオ廃止）**: SAI の PB3〜PB6（4本）、I2C2 の PA8 / PA9（2本、流用しない場合）、ポット PB2（1本）→ **計7本**
- **既存の空き**: 4本 → 合計 **11本** が新たに使える
- **新規に必要な入力**: エンコーダー A/B相 4個×2 = **8本**、押し込みスイッチ **4本** → 計12本

## 設計判断ポイント
1. **押し込みスイッチは74HC165のスキャンチェーンに混ぜる**のが自然。HC165を1個追加すれば8入力増え、エンコーダーA/Bの8本はGPIO直結（高速ポーリング用）に確保できる。これで LQFP48 のまま収まる（残り3本）。
2. もしくは **LQFP64版G491に変更** すればピンに余裕が出るが、C4NDY_BOARDモジュールのフットプリントとメインボードを新規に作り直す前提になる。新規基板なので不可能ではないが、流用度は下がる。
3. QUADSPI外付けFlashは Confiseur のレイアウト保存に関わるため、**残す前提**で数えている。
4. スティック別基板との接続: 1スティックあたり X/Yアナログ2本＋3.3V＋GND。左右で計8本＋共通電源。コネクタはメイン基板側に集約し、角度は筐体固定で付ける（基板自体は通常の平面実装）。

## 基板構成案
- **メイン基板**: G491＋QSPI Flash、キースキャン（HC165/164）、LED、USBコネクタ、エンコーダー2×2ブロック（中央）、スティック用コネクタ×2
- **スティック基板×2**: Adafruit 2765 を載せるだけの小基板。筐体側で手前＋中央への傾斜を付けて固定
- キー基板とメイン基板の関係（現行STKのようにモジュール搭載か、一体化するか）は基板設計フェーズで決定

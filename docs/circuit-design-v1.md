# STKEY 回路設計書 v1

作成: 2026-11-25
参照元: C4NDY プロジェクトの `KiCad/C4NDY_mainboard/C4NDY.kicad_sch` と `KiCad/KVL_STK/`（KVL_STK.kicad_sch / ICs.kicad_sch / LEDs.kicad_sch）を実物から抽出して設計した。

## 1. 全体構成

現行の基板分割を踏襲する。

| 基板 | 役割 | 由来 |
|---|---|---|
| メインボード（モジュール） | MCU、電源、USB-C | C4NDY_mainboard を改修 |
| キーボード基板 | キーマトリクス、LED、スキャンIC、エンコーダー、スティック用コネクタ、C4NDYモジュール受け | KVL_STK を改修 |
| スティック基板 ×2 | Adafruit 2765 のみを搭載する小基板。筐体側で傾斜を付けて固定 | 新規 |

## 2. メインボード（C4NDY_mainboard からの差分）

### そのまま残す
- **U3 MCU**: 回路図シンボルは STM32G4A1CETx（LQFP48）。ファームウェアの .ioc は STM32G491 系表記だが同一パッケージ・ピン互換ファミリであり、現行の組み合わせをそのまま踏襲する
- **U1 MIC39100-3.3WS**: 3.3V LDO と周辺（FB1〜FB3、C1〜C20 の電源まわり）
- **U4 TPS2116DRL**: 電源マルチプレクサ（役割の詳細は要確認事項参照）
- **X1 SG-310SCF**: HSE 発振器
- **J4 USB-C**（5077CR-16SMC2 相当）＋ CC 抵抗 R1/R6 5.1k、DP/DN まわり
- **SW1/SW2 SKRPABE010**: リセット／ブート系スイッチ
- SWD（J7 02x03）、テストポイント、ステータス LED（D1〜D3）
- モジュール外形・コネクタ配置（C4NDY_BOARD フットプリント）: キーボード基板側の受けを流用するため物理配置は維持する

### 削除する（キーボード基板側コネクタへの送出ネット）
- SAI 系 5ネット: SAI_BCLK / SAI_DIN / SAI_DOUT / SAI_LRCLK / SAI_MCLK
- I2C 系 2ネット: I2C_SCL / I2C_SDA（コーデック制御用だったもの）
- POT0 1ネット（ミックスポット用 ADC）

### 再割り当てする
削除で空く **8ネット分** のモジュール間信号を、エンコーダー A/B 相 8本にそのまま割り当てる。

| 旧ネット | 新ネット |
|---|---|
| SAI_BCLK | ENC1_A |
| SAI_LRCLK | ENC1_B |
| SAI_DIN | ENC2_A |
| SAI_DOUT | ENC2_B |
| SAI_MCLK | ENC3_A |
| I2C_SCL | ENC3_B |
| I2C_SDA | ENC4_A |
| POT0 | ENC4_B |

MCU 側のピン対応（現行 .ioc）: PB3 / PB6 / PB5 / PB4 / PA15近傍ではなく SAI/I2C に使っていた PB3〜PB6、PA8、PA9、PB2 がエンコーダー入力になる。PA15 は LED 駆動（TIM8_CH1）のまま維持すること（上表の対応はモジュール間ネット名の対応であり、MCUピンの最終割付はファームウェア設計時に確定する）。

### そのまま維持するモジュール間信号
- 電源系: VBUS / 5V、3.3V、GND
- キースキャン 5本: 165_SL / 165_QH / 165_CLK / 164_CLK / 164_A
- LED 駆動: PA15（ICLED チェーン）
- スティックアナログ 4本: 左右スティックの X/Y（現行の ADC チャネル割付を維持）
- USER_SW / USER_LED / LP_LED（PB10 / PB12 / PB13）

## 3. キーボード基板（KVL_STK からの差分）

### そのまま残す
- キーマトリクス: SW_MEC_5G（Gateron Low Profile 2.0 ソケット）×37＋ 1N4148WT ダイオード（ルートシート）
- LED: Address_LED（ICLED）×34 ＋ 各 100nF（LEDs シート）
- スキャン: 74HC164（U1）＋ 74HC165（U2/U3）
- **U6 MIC2005A**: 電源スイッチ（LED レール等の 5V 制御と推定。要確認事項参照）
- C4NDY モジュール受け（U4 フットプリント）

### 削除する
- **U5 ADAU1761BCPZ** とその周辺受動部品一式（ICs シート）
- オーディオジャック ×2（AudioJack2_Ground、写真の左端パネルの2個）
- **RV1** ミックスポット（POT0）
- **RV2 / RV3 ADA-2765** のオンボード実装（スティック基板へ移設）

### 追加する
1. **ロータリーエンコーダー ×4（中央 2×2 ブロック）**
   - 候補部品: Alps Alpine EC11E 系（押し込みスイッチ付き）または Bourns PEC11R 系。フットプリント確定は部品選定後
   - A/B 相は 10k プルアップ付きでモジュール間ネット ENC1〜4_A/B へ直結（MCU GPIO で高速ポーリング）
   - チャタリング対策はファーム側の状態遷移デコードを基本とし、必要なら基板側に RC（10k / 100nF 級）を追加できるようパターンのみ用意する
2. **74HC165 を 1 個追加（計 3 個）**
   - エンコーダーの押し込みスイッチ ×4 をスキャンチェーンで読むため。チェーンの残り 4 入力は予備（将来の追加スイッチ用）
3. **スティック接続コネクタ ×2**
   - 4 ピン: 3.3V / GND / STK_X / STK_Y
   - 候補: JST PH 4 ピン、または 2.54mm ピンヘッダ。筐体構造と合わせて決定
   - アナログラインにはメイン側に軽いローパス（100Ω ＋ 100nF 級）を入れる余地を残す

## 4. スティック基板（新規）×2

- Adafruit 2765（My_Parts:ADA-2765 フットプリント流用）＋ 4 ピンコネクタのみ
- 能動部品なし。左右は同一基板で共用できる形にする（コネクタ向きで左右を吸収）
- 筐体への傾斜固定（手前＋中央方向）のためのネジ穴を基板に設ける。角度の数値は試作ジグで決定後に反映する

## 5. 電源まわり

- USB バスパワーのみ（現行踏襲）。LED 34 個＋ MCU ＋ スキャン IC の消費電流は現行 STK と同等で、エンコーダー追加分の増加は無視できる範囲
- MIC39100 の 3.3V レール、TPS2116 の構成は現行のまま

## 6. 要確認事項（回路図に落とす前に潰したい点）

1. **QSPI Flash の実装場所**: ファームウェア（.ioc）は QUADSPI を使用し、メインボード回路図にも QSPI_* ネットがあるが、Flash チップのシンボルがメインボード／STK どちらの回路図にも見当たらない。基板側フットプリントのみで実装されている可能性があり、STKEY でどう実装するか決める必要がある
2. **TPS2116 の役割**: 電源入力の二重化（USB と何か）の詳細を現行基板で確認する。不要なら削除して電源を単純化できる
3. **MIC2005A の役割**: 何のレールをスイッチしているか（LED 用 5V と推定）。LED 構成が同じなら残す
4. **エンコーダー部品の選定**: EC11E 系か PEC11R 系か、軸長・ノブとの関係（中央 2×2、ピッチ約 25mm、ノブ径 20mm 級）
5. **モジュール構造の維持可否**: 本書は「メインボード＝モジュール」を維持する前提。MCU をキーボード基板に一体化すればコネクタは減るが、メインボード設計とファームウェアプロジェクト構成の流用度が下がる

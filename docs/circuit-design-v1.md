# STKEY 回路設計書 v1

作成: 2026-11-25（2026-11-25 改訂: メインボードのモジュール構造を廃し、キーボード基板に一体化する方針を反映）
参照元: C4NDY プロジェクトの `KiCad/C4NDY_mainboard/C4NDY.kicad_sch` と `KiCad/KVL_STK/`（KVL_STK.kicad_sch / ICs.kicad_sch / LEDs.kicad_sch）を実物から抽出して設計した。

## 1. 全体構成

**メインボードのモジュール構造は廃止し、MCU をキーボードのメイン基板に一体化する**（ユーザー決定 2026-11-25）。

| 基板 | 役割 | 由来 |
|---|---|---|
| メイン基板（1枚） | キーマトリクス、スキャンIC、エンコーダー、エンコーダー用 RGB LED、スティック用コネクタ、MCU、電源、USB-C | KVL_STK ＋ C4NDY_mainboard を統合・改修 |
| スティック基板 ×2 | Adafruit 2765 のみを搭載する小基板。筐体側で傾斜を付けて固定 | 新規 |

回路図のシート構成案（KiCad 階層）:
- ルートシート: キーマトリクス（現行 KVL_STK ルートシートを踏襲）
- IC シート（旧 ICs）: スキャンIC（キーマトリクス側）、スティックコネクタ（現行 ICs シートからコーデック等を削除し、メインボードの内容を統合）
- ENCODER シート（旧 LEDs）: ロータリーエンコーダー ×4、押し込み読み取り用 74HC165、エンコーダー用 RGB LED ×8（キー用チェーンは廃止し、エンコーダー用に 8 個だけ残した。2026-11-25 にユーザーがエンコーダー関係をこのシートへ集約し、シート名も変更）

## 2. MCU まわり（C4NDY_mainboard から取り込む内容）

### そのまま取り込む
- **MCU**: 回路図シンボルは STM32G4A1CETx（LQFP48）。ファームウェアの .ioc は STM32G491 系表記だが同一パッケージ・ピン互換ファミリであり、現行の組み合わせをそのまま踏襲する
- **MIC39100-3.3WS**: 3.3V LDO と周辺の電源まわり
- **SG-310SCF**: HSE 発振器
- **USB-C コネクタ**（5077CR-16SMC2 相当）＋ CC 抵抗 5.1k ×2、DP/DN まわり。一体化によりメイン基板の端に直接実装する（配置は基板設計で決定。左端の混雑はオーディオ廃止で解消済み）
- **SKRPABE010 ×2**: リセット／ブート系スイッチ
- SWD コネクタ、テストポイント、ステータス LED

### 取り込まない（削除）
- **TPS2116DRL**: 最新メインボードで外部 5V 電源対応のために追加された、USB 供給と外部電源の切り分け用マルチプレクサ（ユーザー確認 2026-11-25）。STKEY は外部電源を持たないため不要。外部 5V 入力コネクタも削除
- **QSPI 増設まわり**: QSPI Flash は現行でもチップ未実装で、信号をコネクタに引き出して外部基板で増設できるようにしてあったもの（同上）。STKEY では増設自体を行わないため削除
- モジュール間コネクタ一式（Conn_01x08 等）と C4NDY_BOARD モジュールフットプリント

## 3. MCU ピン割り当て案（一体化後）

モジュール間ネットの制約がなくなるため、ピンは基板内で自由に割り当て直せる。ファームウェア変更を最小化するため、現行で生きている割り当ては維持し、空いたピンにエンコーダーを割り当てる。

### 維持する（現行 .ioc のまま）
| ピン | 役割 |
|---|---|
| PA11 / PA12 | USB DM / DP |
| PA13 / PA14 | SWD |
| PA15 | LED 駆動（TIM8_CH1、ICLED チェーン ×8、エンコーダー用）。ネット名は RGB_LED |
| PA0 / PB2 / PA4 / PA5 | スティック ADC（X/Y。2026-11-25 回路図監査で確定: RV2 の X=PB2・Y=PA0、RV3 の X=PA4・Y=PA5。旧ポットは PA1） |
| PB7 / PB9 / PC15 | 74HC165 系（SL / QH / CLK） |
| PC13 / PC14 | 74HC164 系（CLK / A） |
| PB10 | USER_SW |
| PB12 / PB13 | USER_LED / LP_LED |
| PF0 | HSE 入力 |

### 新規割り当て（エンコーダー A/B ×8）
旧 SAI（PB3〜PB6）、旧 I2C（PA8 / PA9）、旧 QSPI（PB0 / PB1）を使う。全エンコーダーを近接ピンのペアにそろえた（当初 ENC4 は旧 SAI の PA10 と旧ポットの PA1 の組み合わせだったが、2026-11-25 にユーザーが PB0 / PB1 へ付け替えた）。

| ピン | 信号 |
|---|---|
| PB3 | ENC1_A |
| PB4 | ENC1_B |
| PB5 | ENC2_A |
| PB6 | ENC2_B |
| PA8 | ENC3_A |
| PA9 | ENC3_B |
| PB0 | ENC4_A |
| PB1 | ENC4_B |

ポーリングは GPIOB と GPIOA の 2 ポート読みで足りる（PB 側に 6 本、PA 側に 2 本）。

### 予備（未接続で残す）
PA3 / PA6 / PA7 / PB11（旧 QSPI）、PA1（旧ポット）、PA10（旧 SAI）ほか。一体化後もピンには十分な余裕がある。

※ 2026-11-25 の回路図監査で判明した注意点: 現行メインボード回路図ではスキャン系 5 ピン（PC13 / PC14 / PC15 / PB7 / PB9）は未接続（no_connect）で、キーボード基板側フットプリントとの対応だけで繋がる前提になっていた。STKEY の MCU シートではこの 5 ピンに配線とグローバルラベルを新設済み。また USER_SW は PB10（モジュール上の SW2）、LED0 は PB12（モジュール上のステータス LED）で、いずれも従来どおり MCU まわりに残る。

## 4. キー／スキャン（KVL_STK からの差分）

### そのまま残す
- キーマトリクス: SW_MEC_5G（Gateron Low Profile 2.0 ソケット）×37 ＋ 1N4148WT ダイオード
- スキャン: 74HC164 ×1 ＋ 74HC165 ×2

### 変更する
- **RGB LED はエンコーダー用に 8 個だけ残す**（Address_LED ×8 ＋ 各 100nF、PA15 / RGB_LED 駆動）: 2026-11-25 ユーザー決定。当初はキー用チェーン（×40）ごと廃止したが、同日中にエンコーダー用として 8 個を復活させた。裏面リバースマウント化と 3.3V 駆動を両立できるアドレス式 LED が存在しないこと（SK6812MINI-E は定格 3.7〜5.5V）が背景にあり、LED の型式・実装面は基板設計時に改めて決める。小さいステータス LED（VBUS 表示、PB12 の LED0、PB13 の LED）は別途残す

### 削除する
- **ADAU1761BCPZ** とその周辺受動部品一式
- **MIC2005A**: 外部電源用のレギュレータ IC（ユーザー確認 2026-11-25）。外部電源を持たない STKEY では不要
- オーディオジャック ×2
- **RV1** ミックスポット
- **RV2 / RV3 ADA-2765** のオンボード実装（スティック基板へ移設）
- C4NDY モジュール受けフットプリント（一体化のため）

### 追加する
1. **ロータリーエンコーダー ×4（中央 2×2 ブロック）**
   - **選定: Bourns PEC11R-4220F-S0024**（2026-11-25 選定。当初 Alps EC09E を選んだが単価約¥1,209 と高く、ユーザーの指摘で Bourns に変更）
     - 縦型、φ6mm フラット軸・軸長 20mm、24 デテント（クリック）／24 パルス（1 クリック＝1 パルスでデコードが素直）、押し込みスイッチ付き
     - 回転寿命 30,000 サイクル（EC09E の 2 倍）
     - DigiKey 在庫潤沢（2026-11-25 検索確認: 8,577 個、単価 ¥443）。4 個でも約 ¥1,800 で EC09E の 1 個分以下
     - トレードオフ: 本体は 11mm 級で現行 POT（RK09K1130A5R、9mm 級）より約 2mm 大きい。中央 2×2 ブロック（ピッチ約 25mm）には収まる
     - サイズ最優先の場合の代替: Alps Alpine EC09E1524418（9.5mm 径で POT とほぼ同サイズ、30 デテント／15 パルス、スイッチトラベル 1.5mm。Mouser 在庫 895 個・約¥1,209 を 2026-11-25 確認。寿命 15,000 サイクル）
     - 除外: Bourns PEC09（9mm だが横型＝シャフトが基板と平行で上面実装に不適）
   - A/B 相は 10k プルアップ付きで MCU GPIO へ直結（上記ピン割り当て）
   - チャタリング対策はファーム側の状態遷移デコードを基本とし、必要なら基板側に RC（10k / 100nF 級）を追加できるようパターンのみ用意する
2. **74HC165 を 1 個追加（計 3 個）**
   - エンコーダーの押し込みスイッチ ×4 をスキャンチェーンで読むため。チェーンの残り 4 入力は予備
3. **スティック接続コネクタ ×2**
   - 4 ピン: 3.3V / GND / STK_X / STK_Y
   - **決定（2026-11-25）: JST SH 側面エントリー SM04B-SRSS-TB**（1.0mm ピッチ、SMT、実装高さ 2.95mm）。当初候補の JST PH（B4B-PH-K-S、嵌合高さ 8.0mm）は厚みが気になるため不採用。フットプリント `Connector_JST:JST_SH_SM04B-SRSS-TB_1x04_P1.00mm_Horizontal` を J1/J2 に設定済み。ケーブルは Qwiic/STEMMA QT 用の既製品が流用可（ただしピン順の規格が違うので線色は当てにせず pin 1 合わせ必須）、自作する場合はハウジング SHR-04V-S ＋ コンタクト SSH-003T-P0.2（AWG28〜32）。スティック基板側も同コネクタ
   - アナログラインにはメイン側に軽いローパス（100Ω ＋ 100nF 級）を入れる余地を残す

## 5. スティック基板（新規）×2

- Adafruit 2765（My_Parts:ADA-2765 フットプリント流用）＋ 4 ピンコネクタのみ
- 能動部品なし。左右は同一基板で共用できる形にする（コネクタ向きで左右を吸収）
- 筐体への傾斜固定（手前＋中央方向）のためのネジ穴を基板に設ける。角度の数値は試作ジグで決定後に反映する

## 6. 電源まわり

- **USB バスパワーのみ**。外部 5V 電源まわり（TPS2116、MIC2005A、外部電源入力）はすべて削除し、電源構成を単純化する
- 消費電流は MCU ＋ スキャン IC ＋ RGB LED 8 個が中心で、現行 STK（LED 34 個）より小さい。エンコーダー追加分の増加は無視できる範囲
- 3.3V レールは MIC39100 のまま

## 8. メイン基板の配線作業ルール

`STM32H7S3_Dev_Board_v2` の `JUMBLEQ_mainboard_revD_design.md` にある「積層・配線ルール・電源面」「配線ルール（2026-10-28追加）」「配線幅切替・微小な曲げの全体見直し」と、11月6日の更新を参照する。以下を STKEY の配線とレビューに適用する。

### 配線の形状と接続

- 配線途中は直線と 45° の曲がり、または円弧で構成する。90° 折れは 45° 2 回または円弧で処理する。短い段差や折り返しを省き、通常幅を保てる簡潔な経路を優先する。
- 配線の端点はパッドの中心に置く。辺から入る場合は辺へ直角に、斜めに入る場合は角の方向から接続する。複数の配線が集まる場合は、パッドやビアの外に鋭角のくぼみが残らないようにする。
- 各接続層の配線をビアの中心まで通す。ビア近傍で線幅を切り替える場合はビア中心で切り替え、細線で入る必要がある場合はその幅で中心まで通す。
- 実装パッド内にビアを置かない。新設ビアはランド外周と実装パッドの銅箔の間を **0.15 mm 以上**空ける。パッド近傍の専用 GND ビアは原則としてパッド中心を通る水平・垂直の軸上に置く。
- 電源経路は、実装パッド間やパッドからビア群への接続に局所ゾーンを優先する。複数のビアは直線または格子にそろえ、充填後の銅箔で接続と細りを確認する。
- コンデンサ、抵抗、ICLED の VCC／GND パッドと近傍のビアをトラックで直接つなぐ場合は、線幅 0.50 mm を基本とする。U1～U4 の GND パッドからビアまでの配線も 0.50 mm とする。

### 線幅・積層・帰路

- 低速の一般信号は **0.15 mm** を基本とし、対象ネットを個別に選ぶ。密集部で必要な短区間は現行の最小線幅とクリアランスの範囲で細くできる。USB、発振器・スキャンのクロック、SWD、スティックの ADC、電源は用途ごとに線幅と経路を決める。
- 信号ビアの参照寸法は外径 **0.45 mm**、穴径 **0.20 mm**。STKEY の現行設定は最小穴径 **0.30 mm**、最小ビアリング幅 **0.13 mm**。参照寸法の公称リング幅は **0.125 mm** なので、基板メーカーの条件を確認してビア寸法と DRC 下限をそろえる。電源・GND ビアは電流と用途に応じて選ぶ。
- 4 層の信号配線は `F.Cu` と `B.Cu` に限定する。`In2.Cu` は基板全面の GND 専用層、`In1.Cu` は VCC の全面ベースとする。`In1.Cu` に置く J3 の VBUS 局所ゾーンには、VCC より高い優先度を設定する。
- 裏面 USB の参照面は隣接する `In2.Cu`。USB 差動 90 Ω の線幅・間隔は STKEY の 4 層積層と製造条件に基づいて決める。信号ビアで表裏を切り替える箇所は GND の帰路を確認し、必要に応じて近くの GND ビアで外層の GND と内層を接続する。

### 配線の優先順位

配線前に J3 のランドと非めっき穴、KS-27 ソケット 5 箇所と基板端のクリアランスの処置を決める。電源幹線と J1／J2 の ADC 信号が通る領域も、この段階で確保する。

| 順位 | 対象 | 先に確保する経路 |
| --- | --- | --- |
| 1 | USB FS | **J3 → FB2／FB3 → U6**。J3 の表裏に対応する D+ 同士・D− 同士の合流と、差動ペアの引き出しを最初に試す。J3 から FB1 への VBUS と GND の接続スペースを同時に確保する。 |
| 2 | MCU の局所電源と HSE | U6 の VDD デカップリング、FB4・C95／C96 の VREF+、FB5・C97／C98 の VDDA、および **X1 → R26 → U6 の PF0**。電源パッドからコンデンサと GND までのループ、発振器の出力配線を短くする。 [ST AN5093 §7.4](https://www.st.com/resource/en/application_note/an5093-getting-started-with-stm32g4-series--hardware-development-boards-stmicroelectronics.pdf) |
| 3 | 電源幹線と IC のデカップリング | **J3 → FB1 → U5** の VBUS、U5 の入出力コンデンサと GND、U5 から MCU・スキャン IC・RGB LED 側へ分配する 3.3 V（`VCC`）。U1～U4 のデカップリングもこの段階で接続する。 |
| 4 | スキャンのクロックとシリアル線 | `165_CLK`・`165_SL` と **U3 → U2 → U1 → U6** のデータチェーン、U6→U4 の `164_CLK`・`164_A`。U2 は右端のキー列に近い現位置から試し、クロックの枝や長い並走、ADC 用に確保した経路との干渉を見て配置を確定する。 |
| 5 | スティック ADC・デバッグ | J1／J2 から U6 までの ADC 4 本は参照 GND を連続させ、スキャンのクロックや RGB データとの長い並走を避ける。続いて J4 の SWD とリセット、SW42 の入力、BOOT0 周辺を接続する。 |
| 6 | エンコーダーとキーマトリクス | 中央のエンコーダー A/B 相と押し込み信号を先に通す。キーマトリクスは U4 の `QA`～`QD`、U1／U2 の `Q0`～`Q7`・`Q0_2`・`Q1_2` の幹線を決めてから、各キー・ダイオード・コンデンサへ分岐する。 |
| 7 | LED と残りの枝線 | `RGB_LED` から ICLED1～8 のチェーン、各 LED の局所電源、ステータス LED と残りの低速信号を接続する。 |

最初の配置レビューは、順位 1～3 の引き出しと、順位 4 の U2 経由の試配線ができた段階で行う。

### 優先順位1の実施結果（2026-11-26）

- J3 の両挿入向きの D+／D− を J3 付近で合流させ、FB2／FB3 経由で U6 に接続した。信号は `B.Cu`、信号ビアは 0 個。`In2.Cu` に連続した局所 GND 参照面を設け、J3 のシールド、CC 抵抗の GND、U6 の USB 側 GND を接続した。CC1／CC2 は R24／R25 へ配線し、各抵抗の GND パッドからビアまでは `B.Cu` の幅 0.50 mm の直線で接続した。 [TI の Type-C USB 2.0 配線資料](https://www.ti.com/document-viewer/lit/html/SSZTC87/GUID-E5AE2236-6116-4C43-8618-4F4AF8947651)
- J3 の VBUS 端子 2 箇所から FB1 入力までは、`B.Cu` と `In1.Cu` の局所ゾーンとビア 2 個で接続した。
- 初回の試配線では、差動配線の均一区間を幅 0.145 mm、間隔 0.180 mm とした。試配線時の積層モデル（外層銅厚 0.035 mm、対 `In2.Cu` の誘電体 0.100 mm・Dk 4.5、マスクの Dk 3.3 を仮定）による準静電界の試算は約 92 Ω。J3 の分岐は最長 2.417 mm。
- KiCad 10.0.7 で、ゾーン再充填後の導通、ビア中心、パッドと新設ビアの離隔（最小 0.170 mm）、USB 信号直下の GND を確認した。DRC の新規指摘と回路図との差分は各 0 件。未配線は 443 → 425 件。既存の J3 穴クリアランス 2 件とキーソケットの基板端クリアランス 5 件は製造前の確認事項。実機での USB 接続とインピーダンスは未確認。

### JLCPCB の製造条件と USB 線幅の再計算

- JLCPCB で 4 層、`Specify Stackup: No` の予定。現行の板厚 1.6 mm と標準の外層 1 oz／内層 0.5 oz を前提に、公開表の `No requirement` を設計の基準にする。`B.Cu` から `In2.Cu` までは 7628 プリプレグ 0.2104 mm、Dk 4.4。 [JLCPCB の積層表](https://jlcpcb.com/jp/impedance)
- この断面の準静電界計算では、試配線の幅 0.145 mm／間隔 0.180 mm は約 112 Ω。均一区間を幅 0.270 mm／銅箔間隔 0.180 mm とすると約 90 Ω になる。
- 最終的にパッドへの引き出しを含めて全区間を幅 0.270 mm とした。銅箔間隔 0.180 mm の並走区間は J3 から FB2／FB3 側が 1.300 mm、FB2／FB3 から U6 側が 5.600 mm。FB2／FB3 から U6 までの長さ差は 0.030 mm、J3 の合流部を含めた長さ差は挿入向きにより 0.004 mm または 2.694 mm。
- `In2.Cu` の GND ゾーンを基板外形全体へ拡張した。充填後に銅箔が一つの連続した領域になり、USB 配線全長の直下を覆うことを確認した。内層の信号配線は 0 本。DRC の新規指摘 0 件、回路図との不一致 0 件、GND 接続の追加により未配線は 425 → 417 件。インピーダンスの実測と実機での USB 接続は未確認。

### 優先順位2の実施結果（2026-11-26）

- U6 の VDD 24／36 番は C90／C91 に `B.Cu` の局所ゾーンで接続した。VDD 48 番は C92 に、VBAT 1 番は C94 に配線した。C90／C91／C94 側から `In1.Cu` の VCC 面につなぎ、48 番と C92 は C93 の給電ビアを共用した。VSS と各コンデンサの GND は `In2.Cu` へ接続した。 [ST AN5093 §7.4](https://www.st.com/resource/en/application_note/an5093-getting-started-with-stm32g4-series--hardware-development-boards-stmicroelectronics.pdf)
- VDDA は FB5 と C97／C98、VREF+ は FB4 と C95／C96 をそれぞれ配線し、U6 の 21／20 番へ接続した。C95／C96 と C97／C98 の GND はそれぞれ 0.50 mm の配線でまとめ、近傍のビアで `In2.Cu` の GND 面へ接続した。VSSA 19 番も同じ GND 面に接続した。 [ST AN5346](https://www.st.com/content/st_com/en/technical-documents/an5346-stm32g4-adc-use-tips-and-recommendations-stmicroelectronics.html)
- X1 出力と U6 の PF0 に軸を合わせるため、R26 を X 方向へ 0.0025 mm、Y 方向へ 0.0200 mm 移動した。X1→R26 は 1.600 mm、R26→U6 は 1.638 mm で、どちらも `B.Cu` の直線とした。X1 と C101 の VCC／GND はそれぞれ `B.Cu` 上で 0.50 mm の配線で接続し、GND は両端のビアで `In2.Cu` の GND 面につないだ。 [Epson SG-310SCF データシート](https://download.epsondevice.com/td/pdf/brief/SG-310SDF_en.pdf)
- 再充填後、HSE と USB の配線直下の GND 面、電源ピンとコンデンサ・内層の接続を確認した。基板全体の DRC はエラー 7 件、警告 350 件、未配線 314 件で、回路図との不一致は 0 件だった。HSE の起動・波形、電源波形、ADC ノイズは実機未確認。

### 優先順位3の実施結果（2026-11-26）

- FB1 出力から U5 入力と C85～C87 の VBUS までは `B.Cu` の局所ゾーンで接続した。U5 出力と C88／C89 も `B.Cu` の局所ゾーンで接続した。U5 の GND ピン、放熱タブ、入出力コンデンサの GND は近傍の銅箔とビアで `In2.Cu` に接続した。 [MIC39100 データシート](https://www.microchip.com/content/dam/mchp/documents/OTH/ProductDocuments/DataSheets/20005834A.pdf)
- U5 の3番ピンから C88／C89 の VCC パッドを結ぶ `B.Cu` の出力ゾーンを C89 の左まで延ばした。C89 の左に外径 0.56 mm／穴径 0.30 mm の VCC ビア 3 個を 0.65 mm ピッチで並べ、`In1.Cu` の全面 VCC ゾーンへ接続した。U1～U4 と C1～C4、ICLED1～8 と C45～C52 に給電し、各 GND を接続した。MCU 側の給電点は C93 までとし、U6 各ピンのデカップリング、VDDA／VREF+、HSE は順位 2 で配線する。
- ゾーン充填後、FB1 出力と U5 入力・C85～C87 の間に幅 0.80 mm、`In1.Cu` の C89 側ビアから MCU 側 C93 および右端 U2 側のビアまでに幅 1.20 mm の連続した経路を確認した。`In1.Cu` の VCC 面は一つの領域に連続し、J3 の VBUS 局所ゾーンと離隔している。`In2.Cu` の GND 面は USB 全長の直下を覆う。DRC の新規指摘と回路図との不一致は各 0 件。未配線は順位 3 の着手前の 417 件から 348 件に減った。
- C85／C87 の 10 µF 各 1 個と C86 の 0.1 µF が FB1 後の VBUS にあり、公称容量の合計は 20.1 µF。USB 挿入時の突入電流は製造前の確認事項とする。電源投入波形、負荷時の電圧降下、U5 の温度上昇は未測定。 [NXP AN11392 §2.5](https://www.nxp.com/docs/en/application-note/AN11392.pdf)

### 配線レビュー

- 配線前に既存 DRC を記録し、ビア中心ずれのチェック `track_not_centered_on_via` をエラーに設定する。配線後にゾーンを再充填し、DRC、未配線、回路図との照合結果を確認する。
- DRC に加えて、配線の曲がり、パッド・ビアへの進入形状、パッドとビアの離隔、線幅の切替点、参照 GND 面の連続性を確認する。

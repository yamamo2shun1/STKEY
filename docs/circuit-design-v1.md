# STKEY 回路設計書 v1

作成: 2026-11-25（2026-11-25 改訂: メインボードのモジュール構造を廃し、キーボード基板に一体化する方針を反映）
参照元: C4NDY プロジェクトの `KiCad/C4NDY_mainboard/C4NDY.kicad_sch` と `KiCad/KVL_STK/`（KVL_STK.kicad_sch / ICs.kicad_sch / LEDs.kicad_sch）を実物から抽出して設計した。

## 1. 全体構成

**メインボードのモジュール構造は廃止し、MCU をキーボードのメイン基板に一体化する**（ユーザー決定 2026-11-25）。

| 基板 | 役割 | 由来 |
|---|---|---|
| メイン基板（1枚） | キーマトリクス、LED、スキャンIC、エンコーダー、スティック用コネクタ、MCU、電源、USB-C | KVL_STK ＋ C4NDY_mainboard を統合・改修 |
| スティック基板 ×2 | Adafruit 2765 のみを搭載する小基板。筐体側で傾斜を付けて固定 | 新規 |

回路図のシート構成案（KiCad 階層）:
- ルートシート: キーマトリクス（現行 KVL_STK ルートシートを踏襲）
- ICs シート: MCU、電源、USB、スキャンIC、エンコーダー、スティックコネクタ（現行 ICs シートからコーデック等を削除し、メインボードの内容を統合）
- LEDs シート: 現行のまま

## 2. MCU まわり（C4NDY_mainboard から取り込む内容）

### そのまま取り込む
- **MCU**: 回路図シンボルは STM32G4A1CETx（LQFP48）。ファームウェアの .ioc は STM32G491 系表記だが同一パッケージ・ピン互換ファミリであり、現行の組み合わせをそのまま踏襲する
- **MIC39100-3.3WS**: 3.3V LDO と周辺の電源まわり
- **SG-310SCF**: HSE 発振器
- **USB-C コネクタ**（5077CR-16SMC2 相当）＋ CC 抵抗 5.1k ×2、DP/DN まわり。一体化によりメイン基板の端に直接実装する（配置は基板設計で決定。左端の混雑はオーディオ廃止で解消済み）
- **SKRPABE010 ×2**: リセット／ブート系スイッチ
- SWD コネクタ、テストポイント、ステータス LED

### 取り込まない（削除）
- **TPS2116DRL**: 最新メインボードで外部 5V 電源対応のために追加された、USB 供給と外部電源の切り分け用マルチプレクサ（ユーザー確認 2026-11-25）。STKEY は外部電源を持たないため不要。外部 5V 入力コネクタも削除
- **QSPI 増設まわり**: QSPI Flash は現行でもチップ未実装で、信号をコネクタに引き出して外部基板で増設できるようにしてあったもの（同上）。STKEY では増設自体を行わないため削除
- モジュール間コネクタ一式（Conn_01x08 等）と C4NDY_BOARD モジュールフットプリント

## 3. MCU ピン割り当て案（一体化後）

モジュール間ネットの制約がなくなるため、ピンは基板内で自由に割り当て直せる。ファームウェア変更を最小化するため、現行で生きている割り当ては維持し、空いたピンにエンコーダーを割り当てる。

### 維持する（現行 .ioc のまま）
| ピン | 役割 |
|---|---|
| PA11 / PA12 | USB DM / DP |
| PA13 / PA14 | SWD |
| PA15 | LED 駆動（TIM8_CH1、ICLED チェーン） |
| PA0 / PA1 / PA4 / PA5 | スティック ADC（左右 X/Y、現行チャネル維持） |
| PB7 / PB9 / PC15 | 74HC165 系（SL / QH / CLK） |
| PC13 / PC14 | 74HC164 系（CLK / A） |
| PB10 | USER_SW |
| PB12 / PB13 | USER_LED / LP_LED |
| PF0 | HSE 入力 |

### 新規割り当て（エンコーダー A/B ×8）
旧 SAI（PB3〜PB6）、旧 I2C（PA8 / PA9）、旧 QSPI（PB0 / PB1）を使う。

| ピン | 信号 |
|---|---|
| PB3 | ENC1_A |
| PB4 | ENC1_B |
| PB5 | ENC2_A |
| PB6 | ENC2_B |
| PA8 | ENC3_A |
| PA9 | ENC3_B |
| PB0 | ENC4_A |
| PB1 | ENC4_B |

ポーリングは GPIOB と GPIOA の 2 ポート読みで足りる（PB 側に 6 本、PA 側に 2 本）。

### 予備（未接続で残す）
PA2 / PA3 / PA6 / PA7 / PA10 / PB2（旧ポット）/ PB8 / PB11（旧 QSPI NCS）/ PF1 ほか。一体化後もピンには十分な余裕がある。

## 4. キー／LED／スキャン（KVL_STK からの差分）

### そのまま残す
- キーマトリクス: SW_MEC_5G（Gateron Low Profile 2.0 ソケット）×37 ＋ 1N4148WT ダイオード
- LED: Address_LED（ICLED）×34 ＋ 各 100nF
- スキャン: 74HC164 ×1 ＋ 74HC165 ×2

### 削除する
- **ADAU1761BCPZ** とその周辺受動部品一式
- **MIC2005A**: 外部電源用のレギュレータ IC（ユーザー確認 2026-11-25）。外部電源を持たない STKEY では不要
- オーディオジャック ×2
- **RV1** ミックスポット
- **RV2 / RV3 ADA-2765** のオンボード実装（スティック基板へ移設）
- C4NDY モジュール受けフットプリント（一体化のため）

### 追加する
1. **ロータリーエンコーダー ×4（中央 2×2 ブロック）**
   - **選定: Alps Alpine EC09E1524418**（2026-11-25 選定。ユーザー条件: クリック感＋押し込みスイッチ付き、サイズは現行 POT = RK09K1130A5R に近いこと）
     - RK09K と同じ Alps 9mm プラットフォームの縦型。本体 9.5mm 径、高さ 11.5mm で現行 POT とほぼ同サイズ
     - 30 デテント（クリック）／15 パルス、プッシュオンスイッチ付き（トラベル 1.5mm、操作力 6N 級）、軸は φ6mm フラット・長さ 20mm
     - 定格 10mA 5V DC（3.3V 駆動で問題なし）、回転寿命 15,000 サイクル、スイッチ寿命 10,000 回
     - Mouser 取扱いあり（2026-11-25 確認: 在庫 895 個、単価 約¥1,209）。同フットプリントでスイッチトラベル 0.5mm の EC09E1524417 もあり（同日在庫 679 個、約¥1,139）、押し心地を変えたくなったら基板変更なしで差し替え可能
     - 検討して除外したもの: Bourns PEC09（9mm だが横型＝シャフトが基板と平行で上面実装に不適）、EC11E 系（11mm で POT より一回り大きい）
     - ファーム側メモ: 15 パルス／30 デテントのため、1 クリック＝1 カウントになるようエッジ検出ベースでデコードする
   - A/B 相は 10k プルアップ付きで MCU GPIO へ直結（上記ピン割り当て）
   - チャタリング対策はファーム側の状態遷移デコードを基本とし、必要なら基板側に RC（10k / 100nF 級）を追加できるようパターンのみ用意する
2. **74HC165 を 1 個追加（計 3 個）**
   - エンコーダーの押し込みスイッチ ×4 をスキャンチェーンで読むため。チェーンの残り 4 入力は予備
3. **スティック接続コネクタ ×2**
   - 4 ピン: 3.3V / GND / STK_X / STK_Y
   - 候補: JST PH 4 ピン、または 2.54mm ピンヘッダ。筐体構造と合わせて決定
   - アナログラインにはメイン側に軽いローパス（100Ω ＋ 100nF 級）を入れる余地を残す

## 5. スティック基板（新規）×2

- Adafruit 2765（My_Parts:ADA-2765 フットプリント流用）＋ 4 ピンコネクタのみ
- 能動部品なし。左右は同一基板で共用できる形にする（コネクタ向きで左右を吸収）
- 筐体への傾斜固定（手前＋中央方向）のためのネジ穴を基板に設ける。角度の数値は試作ジグで決定後に反映する

## 6. 電源まわり

- **USB バスパワーのみ**。外部 5V 電源まわり（TPS2116、MIC2005A、外部電源入力）はすべて削除し、電源構成を単純化する
- LED 34 個 ＋ MCU ＋ スキャン IC の消費電流は現行 STK と同等で、エンコーダー追加分の増加は無視できる範囲
- 3.3V レールは MIC39100 のまま

## 7. 要確認事項（回路図に落とす前に潰したい点）

1. ~~**QSPI Flash の実装場所**~~ — 解決（2026-11-25、ユーザー確認）: 現行でもチップは未実装で、ピンだけコネクタに引き出して外部基板で増設可能にしてあった。STKEY では増設まわりごと削除
2. ~~**TPS2116 の役割**~~ — 解決（同上）: 外部 5V 電源との切り分け。STKEY では外部電源ごと削除
3. ~~**MIC2005A の役割**~~ — 解決（同上）: 外部電源用のレギュレータ IC。STKEY では削除
4. ~~**エンコーダー部品の選定**~~ — 解決（2026-11-25）: Alps Alpine **EC09E1524418** に決定（上記「追加する」参照）。ノブは φ6mm D 軸用、径 20mm 級を想定
5. ~~**モジュール構造の維持可否**~~ — 解決（2026-11-25、ユーザー決定）: モジュール構造は廃止し、MCU をキーボードのメイン基板に一体化する

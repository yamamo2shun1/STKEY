# STKEY 回路設計書 v1

作成: 2026-11-25（2026-11-25 改訂: メインボードのモジュール構造を廃し、キーボード基板に一体化する方針を反映）
参照元: C4NDY プロジェクトの `KiCad/C4NDY_mainboard/C4NDY.kicad_sch` と `KiCad/KVL_STK/`（KVL_STK.kicad_sch / ICs.kicad_sch / LEDs.kicad_sch）を実物から抽出して設計した。

## 1. 全体構成

**メインボードのモジュール構造は廃止し、MCU をキーボードのメイン基板に一体化する**（ユーザー決定 2026-11-25）。

| 基板 | 役割 | 由来 |
|---|---|---|
| メイン基板（1枚） | キーマトリクス、スキャンIC、エンコーダー、エンコーダー用 RGB LED、スティック用コネクタ、MCU、電源、USB-C | KVL_STK ＋ C4NDY_mainboard を統合・改修 |
| スティック基板 ×2 | Adafruit 2765 のみを搭載する小基板。筐体側で傾斜を付けて固定 | 新規 |

回路図のシート構成案（KiCad 階層）:
- ルートシート: キーマトリクス（現行 KVL_STK ルートシートを踏襲）
- IC シート（旧 ICs）: スキャンIC（キーマトリクス側）、スティックコネクタ（現行 ICs シートからコーデック等を削除し、メインボードの内容を統合）
- ENCODER シート（旧 LEDs）: ロータリーエンコーダー ×4、押し込み読み取り用 74HC165、エンコーダー用 RGB LED ×8（キー用チェーンは廃止し、エンコーダー用に 8 個だけ残した。2026-11-25 にユーザーがエンコーダー関係をこのシートへ集約し、シート名も変更）

## 2. MCU まわり（C4NDY_mainboard から取り込む内容）

### そのまま取り込む
- **MCU**: 回路図シンボルは STM32G4A1CETx（LQFP48）。ファームウェアの .ioc は STM32G491 系表記だが同一パッケージ・ピン互換ファミリであり、現行の組み合わせをそのまま踏襲する
- **MIC39100-3.3WS**: 3.3V LDO と周辺の電源まわり
- **SG-310SCF**: HSE 発振器
- **USB-C コネクタ**（5077CR-16SMC2 相当）＋ CC 抵抗 5.1k ×2、DP/DN まわり。一体化によりメイン基板の端に直接実装する（配置は基板設計で決定。左端の混雑はオーディオ廃止で解消済み）
- **SKRPABE010 ×2**: リセット／ブート系スイッチ
- SWD コネクタ、テストポイント、ステータス LED

### 取り込まない（削除）
- **TPS2116DRL**: 最新メインボードで外部 5V 電源対応のために追加された、USB 供給と外部電源の切り分け用マルチプレクサ（ユーザー確認 2026-11-25）。STKEY は外部電源を持たないため不要。外部 5V 入力コネクタも削除
- **QSPI 増設まわり**: QSPI Flash は現行でもチップ未実装で、信号をコネクタに引き出して外部基板で増設できるようにしてあったもの（同上）。STKEY では増設自体を行わないため削除
- モジュール間コネクタ一式（Conn_01x08 等）と C4NDY_BOARD モジュールフットプリント

## 3. MCU ピン割り当て案（一体化後）

モジュール間ネットの制約がなくなるため、ピンは基板内で自由に割り当て直せる。ファームウェア変更を最小化するため、現行で生きている割り当ては維持し、空いたピンにエンコーダーを割り当てる。

### 維持する（現行 .ioc のまま）
| ピン | 役割 |
|---|---|
| PA11 / PA12 | USB DM / DP |
| PA13 / PA14 | SWD |
| PA15 | LED 駆動（TIM8_CH1、ICLED チェーン ×8、エンコーダー用）。ネット名は RGB_LED |
| PA0 / PB2 / PA4 / PA5 | スティック ADC（X/Y。2026-11-25 回路図監査で確定: RV2 の X=PB2・Y=PA0、RV3 の X=PA4・Y=PA5。旧ポットは PA1） |
| PB7 / PB9 / PC15 | 74HC165 系（SL / QH / CLK） |
| PC13 / PC14 | 74HC164 系（CLK / A） |
| PB10 | USER_SW |
| PB12 / PB13 | USER_LED / LP_LED |
| PF0 | HSE 入力 |

### 新規割り当て（エンコーダー A/B ×8）
旧 SAI（PB3〜PB6）、旧 I2C（PA8 / PA9）、旧 QSPI（PB0 / PB1）を使う。全エンコーダーを近接ピンのペアにそろえた（当初 ENC4 は旧 SAI の PA10 と旧ポットの PA1 の組み合わせだったが、2026-11-25 にユーザーが PB0 / PB1 へ付け替えた）。

| ピン | 信号 |
|---|---|
| PB3 | ENC1_A |
| PB4 | ENC1_B |
| PB5 | ENC2_A |
| PB6 | ENC2_B |
| PA8 | ENC3_A |
| PA9 | ENC3_B |
| PB0 | ENC4_A |
| PB1 | ENC4_B |

ポーリングは GPIOB と GPIOA の 2 ポート読みで足りる（PB 側に 6 本、PA 側に 2 本）。

### 予備（未接続で残す）
PA3 / PA6 / PA7 / PB11（旧 QSPI）、PA1（旧ポット）、PA10（旧 SAI）ほか。一体化後もピンには十分な余裕がある。

※ 2026-11-25 の回路図監査で判明した注意点: 現行メインボード回路図ではスキャン系 5 ピン（PC13 / PC14 / PC15 / PB7 / PB9）は未接続（no_connect）で、キーボード基板側フットプリントとの対応だけで繋がる前提になっていた。STKEY の MCU シートではこの 5 ピンに配線とグローバルラベルを新設済み。また USER_SW は PB10（モジュール上の SW2）、LED0 は PB12（モジュール上のステータス LED）で、いずれも従来どおり MCU まわりに残る。

## 4. キー／スキャン（KVL_STK からの差分）

### そのまま残す
- キーマトリクス: SW_MEC_5G（Gateron Low Profile 2.0 ソケット）×37 ＋ 1N4148WT ダイオード
- スキャン: 74HC164 ×1 ＋ 74HC165 ×2

### 変更する
- **RGB LED はエンコーダー用に 8 個だけ残す**（Address_LED ×8 ＋ 各 100nF、PA15 / RGB_LED 駆動）: 2026-11-25 ユーザー決定。当初はキー用チェーン（×40）ごと廃止したが、同日中にエンコーダー用として 8 個を復活させた。裏面リバースマウント化と 3.3V 駆動を両立できるアドレス式 LED が存在しないこと（SK6812MINI-E は定格 3.7〜5.5V）が背景にあり、LED の型式・実装面は基板設計時に改めて決める。小さいステータス LED（VBUS 表示、PB12 の LED0、PB13 の LED）は別途残す

### 削除する
- **ADAU1761BCPZ** とその周辺受動部品一式
- **MIC2005A**: 外部電源用のレギュレータ IC（ユーザー確認 2026-11-25）。外部電源を持たない STKEY では不要
- オーディオジャック ×2
- **RV1** ミックスポット
- **RV2 / RV3 ADA-2765** のオンボード実装（スティック基板へ移設）
- C4NDY モジュール受けフットプリント（一体化のため）

### 追加する
1. **ロータリーエンコーダー ×4（中央 2×2 ブロック）**
   - **選定: Bourns PEC11R-4220F-S0024**（2026-11-25 選定。当初 Alps EC09E を選んだが単価約¥1,209 と高く、ユーザーの指摘で Bourns に変更）
     - 縦型、φ6mm フラット軸・軸長 20mm、24 デテント（クリック）／24 パルス（1 クリック＝1 パルスでデコードが素直）、押し込みスイッチ付き
     - 回転寿命 30,000 サイクル（EC09E の 2 倍）
     - DigiKey 在庫潤沢（2026-11-25 検索確認: 8,577 個、単価 ¥443）。4 個でも約 ¥1,800 で EC09E の 1 個分以下
     - トレードオフ: 本体は 11mm 級で現行 POT（RK09K1130A5R、9mm 級）より約 2mm 大きい。中央 2×2 ブロック（ピッチ約 25mm）には収まる
     - サイズ最優先の場合の代替: Alps Alpine EC09E1524418（9.5mm 径で POT とほぼ同サイズ、30 デテント／15 パルス、スイッチトラベル 1.5mm。Mouser 在庫 895 個・約¥1,209 を 2026-11-25 確認。寿命 15,000 サイクル）
     - 除外: Bourns PEC09（9mm だが横型＝シャフトが基板と平行で上面実装に不適）
   - A/B 相は 10k プルアップ付きで MCU GPIO へ直結（上記ピン割り当て）
   - チャタリング対策はファーム側の状態遷移デコードを基本とし、必要なら基板側に RC（10k / 100nF 級）を追加できるようパターンのみ用意する
2. **74HC165 を 1 個追加（計 3 個）**
   - エンコーダーの押し込みスイッチ ×4 をスキャンチェーンで読むため。チェーンの残り 4 入力は予備
3. **スティック接続コネクタ ×2**
   - 4 ピン: 3.3V / GND / STK_X / STK_Y
   - 候補: JST PH 4 ピン、または 2.54mm ピンヘッダ。筐体構造と合わせて決定
   - アナログラインにはメイン側に軽いローパス（100Ω ＋ 100nF 級）を入れる余地を残す

## 5. スティック基板（新規）×2

- Adafruit 2765（My_Parts:ADA-2765 フットプリント流用）＋ 4 ピンコネクタのみ
- 能動部品なし。左右は同一基板で共用できる形にする（コネクタ向きで左右を吸収）
- 筐体への傾斜固定（手前＋中央方向）のためのネジ穴を基板に設ける。角度の数値は試作ジグで決定後に反映する

## 6. 電源まわり

- **USB バスパワーのみ**。外部 5V 電源まわり（TPS2116、MIC2005A、外部電源入力）はすべて削除し、電源構成を単純化する
- 消費電流は MCU ＋ スキャン IC ＋ RGB LED 8 個が中心で、現行 STK（LED 34 個）より小さい。エンコーダー追加分の増加は無視できる範囲
- 3.3V レールは MIC39100 のまま

## 7. 要確認事項（回路図に落とす前に潰したい点）

1. ~~**QSPI Flash の実装場所**~~ — 解決（2026-11-25、ユーザー確認）: 現行でもチップは未実装で、ピンだけコネクタに引き出して外部基板で増設可能にしてあった。STKEY では増設まわりごと削除
2. ~~**TPS2116 の役割**~~ — 解決（同上）: 外部 5V 電源との切り分け。STKEY では外部電源ごと削除
3. ~~**MIC2005A の役割**~~ — 解決（同上）: 外部電源用のレギュレータ IC。STKEY では削除
4. ~~**エンコーダー部品の選定**~~ — 解決（2026-11-25）: Bourns **PEC11R-4220F-S0024** に決定（上記「追加する」参照）。ノブは φ6mm D 軸用、径 20mm 級を想定
5. ~~**モジュール構造の維持可否**~~ — 解決（2026-11-25、ユーザー決定）: モジュール構造は廃止し、MCU をキーボードのメイン基板に一体化する

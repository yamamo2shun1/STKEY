# C4NDY STKベース新キーボード 仕様整理 v0.1

作成: 2026-11-25（決定事項の集約。未決定事項は末尾に明記）

## コンセプト
- C4NDY STK（37キー、STM32G491、TinyUSB）をベースにした新プロジェクト。新規GitHubリポジトリで開発する。
- **オーディオ機能は搭載しない**（デバイスをキメラ化させないため）。Vinyl Tracer連携は本機の役割から外す。
- USB **HID + MIDI 複合デバイス** とする。

## キー部
- 配列は STK と同じ **横10列 × 縦4行** のオーソリニア。現行のマトリクス／スキャン構成（74HC165/164）と Confiseur の TOML レイアウト構造を流用する。
- キースイッチは現行通り Gateron Low Profile 2.0 + KS-27 ホットスワップを前提とする。
- 左右5列ずつのクラスタの間を広げ、中央にスペースを作る（現行STKで左端に寄っていたコネクタ類の混雑は、オーディオ廃止により解消する）。

## ロータリーエンコーダー
- **4個**、中央に **2×2ブロック** で配置する。キーは置き換えず、中央の余白に収める。
- 寸法目安: エンコーダーピッチ約25mm、ブロック占有 約45×45mm、ノブ径20mm級。
- ブロックの上下位置は4行の中央（2行目と3行目の高さ）を初期想定とする。
- 読み取りは GPIO の高速ポーリング＋状態遷移デコードを基本とし、押し込みスイッチの扱い（マトリクスに混ぜるか独立入力か）は未定。

## ジョイスティック
- 素子は STK と同じ **Adafruit 2765 Mini 2-Axis Analog Thumbstick**（10kΩ×2軸）を継続採用する。
  - 入手性確認済み（2026-11-25）: DigiKey日本 在庫562個・¥412・Part Status Active / Mouser 在庫46個・$2.50 / Adafruit公式 IN STOCK。
  - ホビー流通品のため供給保証はない。販売を見据える場合は必要数＋予備を早期に確保する。
- スティックはメイン基板から分離し、**別基板＋筐体側の固定で角度を付ける**。
- **向き（確定）**: 左右対称に、スティック軸を **手前＋中央方向** へ倒す。左スティックは右手前、右スティックは左手前を向く。親指が上から面で押し込む形にし、従来困難だった内側方向への入力を受けやすくする。
- 前傾・内傾の具体的な角度は未定。角度可変の試作ジグで決める（初期値候補: 前傾20〜30°、内傾15〜20°）。

## MCU / ファームウェア
- **STM32G491（現行）継続が最有力**。HID+MIDIなら USB Full-Speed で十分で、内蔵Flash 512KBで完結する。
- 流用資産: TinyUSB の HID 実装、カスタムブートローダー（DFU更新）、Confiseur によるリマップ。
- 追加実装: TinyUSB MIDI クラスの複合構成（エンドポイント配分が要点）。
